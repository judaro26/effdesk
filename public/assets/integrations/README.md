# Integration provider marks

SVG marks are self-hosted so the integration catalog does not depend on third-party image hosts or require external image sources in the desk Content Security Policy.

- Simple Icons marks (Okta, PagerDuty, HubSpot, Zapier, Make, n8n, Datadog, Grafana, Splunk, Sentry, GitHub, GitLab, Jira, Linear) are sourced from https://github.com/simple-icons/simple-icons and distributed under CC0 1.0. Brand names and marks remain trademarks of their respective owners.
- Slack, Microsoft Teams, Google Workspace, Microsoft Intune, AWS, Azure, Salesforce, Microsoft Defender, and CrowdStrike marks are sourced from https://github.com/glincker/thesvg. Product marks remain the property of their respective owners and are used only to identify integrations.
- The Microsoft four-square corporate mark is used for Microsoft Entra ID and Microsoft Intune labels where a product-specific Entra mark is not bundled. It is not represented as a dedicated Entra product icon.
- Rootly, FireHydrant, and Jamf currently use compact, locally drawn provider marks informed by their public brand identity; these are not official downloadable artwork. Zoho Cliq uses the existing inline mark. Replace these marks with approved official artwork if the providers supply distributable assets.

Do not recolor source marks. The UI controls only their display size and containment.
